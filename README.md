# Titanic-Data-Analysis

# Introduction

This repository contains an Exploratory Data Analysis (EDA) project on the Titanic dataset.
The goal of this project is to analyze the dataset, visualize key insights, and derive meaningful conclusions using various data analysis techniques.

# Dataset

The dataset used in this project is the famous Titanic dataset, which contains information about passengers on the Titanic, including whether they survived or not, their age, gender, class, and other features.
You can find the dataset on Kaggle or use the one included in this repository.


# The key libraries used include:

Pandas

NumPy

Matplotlib

Seaborn


# EDA Process

The following steps are covered in the EDA:

Data Loading: Importing and inspecting the dataset.

Data Cleaning: Handling missing values, duplicates, and incorrect data types.

Exploratory Analysis: Understanding distributions, correlations, and relationships between features.

Data Visualization: Using plots and graphs to uncover trends and insights.

Feature Engineering: Creating new meaningful features.

# Summary & Insights: Conclusion based on the findings.

# Results & Insights

Some key insights from the analysis:

Women had a higher survival rate compared to men.

Passengers in first class had a significantly higher survival rate.

Younger passengers had a better chance of survival.

Certain features like fare and cabin location influenced survival probability.
